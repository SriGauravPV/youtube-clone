# 📺 YouTube Clone

A fully responsive and feature-rich **YouTube Clone** built to simulate core functionalities of YouTube such as video streaming, searching, categories, and channel views.

---

## 🔥 Features

- 🎥 Watch embedded videos (YouTube API or custom uploads)
- 🔍 Search for videos by keywords
- 📂 Browse videos by category
- 📱 Responsive design for all screen sizes

---

## 🛠️ Tech Stack

- **Frontend:** React.js / HTML / CSS / Tailwind / Bootstrap
- **API:** YouTube Data API v3
- **Authentication:** Firebase / OAuth (if implemented)
